# Migrating from aio-rs 0.4 to 0.5

Every breaking change from 0.4.2 to 0.5.0, each with its before and after
(the [changelog](../../CHANGELOG.md) says why). The data needs nothing: 0.5
opens 0.4's store as it is, and an `aio.toml` that 0.4 read still reads
but for a `"0s"` where a second is now the least ([aio.toml](#aiotoml)).

1. Move the dependency: `ax pin 0.5.0`.
2. `cargo check --all-targets`: the compiler finds the renamed and retyped
   items ([Rust](#rust)); fix them with the tables below.
3. Read [Behavior](#behavior): what the compiler can't find.
4. Optionally, write `aio.toml`'s times as spans ([aio.toml](#aiotoml)).

## Rust

### Cells and refusals

| 0.4 | 0.5 |
|---|---|
| `e.code()` on an `aio::Rejected` | `e.code`, the field (as `e.why`): `e.code == Some(Code::ActionRefused)`; `e.code.clone()` where it must be owned |
| `aio::report::Code`, `Code::of(kind)`, `Code::Panic` | `aio::report::Problem`, `Problem::of(kind)`, `Problem::Panic` |
| `d.code()` on a `report::Diagnostic` | `d.problem()`; `d.error_code()` is as before |
| `T::ASYNC`, `T::TTL`, `T::PERSIST`, `T::TABLES`… of `aio::Cell` / `aio::CellData` | the same (hidden from the docs: the macros' plumbing, no longer promised); `ID`, `VERSION`, `METHODS`, `SIGNATURES`, `CLIENT`, `SCHEDULES`, `SERVER` and `TRANSIENT` stay |
| `aio::update::sign(..)`, `check(..)`, `keygen()`… returning `Result<_, String>` | `Result<_, aio::update::UpdateError>`: `?` into your own error, or `.map_err(\|e\| e.to_string())` for the old text |
| `impl aio::update::Runtime` with `check`/`apply` returning `Err(String)` | `Err(UpdateError::Other(why))`; an `io::Error` converts with `?`. A veto (`can_apply`) is still a `String` |
| `aio::http::CookieOpts { expires: Some(chrono_time), .. }` | `expires: Some(std::time::SystemTime)`: `SystemTime::now() + Duration::from_secs(3600)` |
| `cron.next_in(&tz, after)` | `cron.next(after)`: local time or UTC, as `aio::cron::set_local(bool)` says |
| `aio::auth::budget::{Meter, Guesses, FAILS, ..}` | gone: the login doors keep their own budgets; `aio::cost` is hidden plumbing (`ax cost` shows it) |

### Views

| 0.4 | 0.5 |
|---|---|
| `Code::KeyA` from `aio::ui::prelude` (a key's place) | `KeyCode::KeyA`: `Code` is a refusal's code (`aio::prelude`) |
| `Effect` from `aio::ui::prelude` (what `effect(..)` returns) | `aio::ui::Effect`: `Effect` in `aio::prelude` is a cell's |
| `let t: Toast = toast(..)`, `toast_for(..)` | `toast_handle(text, tone, stay)` gives the `Toast`; `toast`, `toast_for` and `toast_view` return `()` (a match arm needs no `_ =`) |
| `e.scroll_to(true)` on a `MountedData` | `e.scroll_to(ScrollBehavior::Smooth)`; `false` is `ScrollBehavior::Instant` |
| `Prop::Const(v)`, `Prop::Live(m)`, a `match` on a `Prop` | `Prop::new(v)` (or `v.into()`), `Prop::from(m)`; read it with `get`, `with`, `is_live`. A `Prop<T>` is `Copy` for every `T` now |
| `#[derive(Props)] struct RowProps { .. }` placed by `rsx!` | `#[derive(Clone, Props)]`: a component's props are compared and kept to follow a plain prop |
| `GuestEvent::Navigated { url, back, forward }` in a pattern | add `in_page` (`true`: the same document moved, a hash or `pushState`), or `..` |
| a `match` over `GuestEvent` naming every kind | end it with `_ => {}`: it is `#[non_exhaustive]` (`LoadFailed` is new) |
| a literal naming every field of `aio_shell::Web`, `aio::config::Home`, `aio::config::AndroidBuild`, `aio::web::storage::Doc`, `air::Raw` | add `schemes: &[]`, `moved: vec![]`, `biometric: false`, `done: vec![]` (the calls answered lately), `field: false`; or end it with `..Default::default()` |
| `aio::ui::Tab` (a browser tab's place) | `aio::ui::BrowserTab` |
| `aio::http::Tab` (`Http::ui`'s tab) | `aio::http::TabWire` |
| a module named `prelude` beside `aio::client!(..)` | `client!` makes `prelude` there (its items and the view API, for `use crate::prelude::*;` in other modules): rename yours, or move the `client!` into a module |

### Tests

| 0.4 | 0.5 |
|---|---|
| `t.advance(60_000)` on `TestCells` | `t.advance(Duration::from_secs(60))` (`use std::time::Duration;`), as `TestUi::advance` takes |
| `t.advance(-1000)` (a clock step back) | `t.rewind(Duration::from_secs(1))` |
| `t.settle_for(500)` | `t.settle_for(Duration::from_millis(500))` |
| `t.budget::<C>("m", 15)` | `t.budget::<C>("m", Duration::from_millis(15))` |
| `aio::perf::Budgets { call_ceiling: Some(1000), .. }` | `call_ceiling: Some(Duration::from_secs(1))`; `method`, `effect`, `methods` and `effects` are `Duration`s too |
| `ui.click("fleet")` where two showing elements have `data-t="fleet"` | `TestUi` refuses it, naming both: give each its own handle, or name one inside another (`ui.click("side/fleet")`) |

### aio.toml in Rust

The `aio::config` fields whose `aio.toml` key became a span are
`Duration`s:

| 0.4 | 0.5 |
|---|---|
| `cfg.data.coalesce_ms` (`u64`) | `cfg.data.coalesce` |
| `cfg.server.limits.sync_interval_ms` | `cfg.server.limits.sync_interval` |
| `splash.min_ms`, `max_ms`, `fade_ms` | `splash.min`, `max`, `fade` (`Option`) |
| `cfg.log.heartbeat` (`u64` seconds, `0`: none) | `Option<Duration>` (`None`: off) |
| `cfg.build.budget_mb` (`Option<u64>`) | `Option<f64>`: `Some(14.0)` |
| `aio::vitals::Tier { degraded: 50, .. }` (`render`, `transport`, `loop`), `t.event_loop.frozen` as ms | `Tier { degraded: Duration::from_millis(50), .. }`, a `Duration`; `grade(ms)` is as before |
| `cfg.vitals.queue` (a `Tier`) | an `aio::vitals::Counts` (`degraded`, `warning`, `frozen`: effects waiting) |
| `aio::config::App { id, name, .. every field }` | add `schemes: vec![]` (deep links); better, end the literal with `..Default::default()`: a key added later then breaks nothing |

### The shell

`aio_shell`'s `runtime`, `splash`, `place`, `prune`, `pidlock`,
`macmove`, `oneclick`, `fuses`, `swap`, `switches`, `inspect` and `delta`,
`html_open`, every `aio_shell::update` item but `cell` and `stub`,
`instance::{hand_over, programs, quit_at, DEV_ARGS}`,
`guest::preload_refusal` and `page::char_index` are ax's plumbing, hidden
from the docs. Code that names one still compiles, with no promise it
will next release: if an app needs one, open an issue for an API.

## aio.toml

Every time is a span now, with `ms` as a unit: `"250ms"`, `"30s"`, `"5m"`,
`"12h"`, `"1d"` ([value types](../reference/aio-toml.md#value-types)).
The old keys and bare numbers still read, so nothing has to change;
the new spelling is the one the docs show:

```diff
 [data]
-coalesce_ms = 100
+coalesce = "100ms"

 [server.limits]
-sync_interval_ms = 50
+sync_interval = "50ms"

 [build.splash]
-min_ms = 400
-max_ms = 15000
-fade_ms = 200
+min = "400ms"
+max = "15s"
+fade = "200ms"

 [log]
-heartbeat = 3600
+heartbeat = "1h"      # or "off" (was 0)

 [perf]
-method = 50
-call_ceiling = 30000
+method = "50ms"
+call_ceiling = "30s"

 [perf.methods]
-"notes.import" = 2000
+"notes.import" = "2s"

 [vitals.loop]
-frozen = 2000
+frozen = "2s"          # [vitals.queue] stays a count of effects
```

Two keys changed what they take:

- `[build] budget_mb` takes a fraction (`14.5`) or a size as `[budgets]`
  writes one (`"14.5MB"`); a whole number reads as before.
- A span under a second is refused where a second was the least before
  (`[history] keep`, `[feedback] timeout`, `[data] backup_every` and
  `snapshot_every`, `[client] retention`, `[updates] every`): a backup
  every millisecond is a typo.

The method attributes take spans too, through the same parser:
`#[ttl("1m")]`, `#[long("2m")]`, `#[every("500ms")]`; a number is still ms.

## Behavior

What compiles as before and acts differently:

| Where | 0.4 | 0.5 |
|---|---|---|
| The kit's theme | a bare `<main>` was a centred, padded column; a top-level `<header>`/`<footer>` a full-bleed bar | opt-in: `class: "container"` on `main` (or any box), on a `header` or `footer` for the bar ([theming](../ui/theming.md)); a bare `<main>` is the app's to lay out |
| A `Browser`'s guest | any `src` loaded (`file:`, `data:`, `javascript:`…) | http(s) and `about:blank` only; another scheme when the window lists it: `Web { schemes: &["data"], .. }`. A refusal is said (`<Browser> load REFUSED`) |
| `TestUi` and a `data-t` two showing elements share | read the first | refused, naming both ([testing](../testing/ui.md#finding-elements)) |
| A component's plain props | read once | followed: when what they read changes and the props differ, the body runs again with its state kept |
| `ax upgrade` to a release before 0.5.0 | ran its install script | refused: those releases are unsigned (their `install.sh` still installs them) |
| The window's spellchecker (Linux; Windows for a language the OS lacks) | fetched the person's dictionary from Google's CDN on first launch | fetches none unless `[capabilities] network` reaches `*.gvt1.com`; a dictionary already in the profile is still used ([privacy](../clients/desktop.md#privacy)) |
| `ax status --json` | a bare list; an unknown app as text on stderr | ax's one object, as every verb: `{"ok": …, "value": [..]}` (`error`, `exit` when an app isn't started): read `.value` |
| `ax` and a wrong command line a verb finds as it runs (`--last abc`, an unknown `--template`) | exit 1 | exit 2, as for any usage error |
